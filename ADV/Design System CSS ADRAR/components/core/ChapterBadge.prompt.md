Marqueur de chapitre numéroté, utilisé en diapositive de transition entre sections d'un support de formation.

```jsx
<ChapterBadge number="02" label="Qu'est-ce qu'un pourcentage ?" />
```

Sur fond `var(--surface-app)` (prune). Le numéro est mis en avant en `--text-chapter-number`; le label est optionnel pour un usage en simple repère de progression.
